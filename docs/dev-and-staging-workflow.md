# MalMoi 개발/스테이징 운영 루틴

본 문서는 MalMoi의 확정 운영 방향을 기준으로,  
**맥미니(개발) + 28 서버(외부 테스트 스테이징)** 하이브리드 루틴을 정리한 기준 문서입니다.

---

## 1) 환경 역할 분리 (확정)

## 맥미니 (개발 전용)
- 역할
  - 기능 추가/수정
  - UI/UX 개선
  - 내부 확인
- 특징
  - 빠른 수정/반복
  - 로컬 실행 중심
  - 외부 공개하지 않음

## 28 서버 (외부 테스트용 스테이징)
- 역할
  - 외부 접속 검증
  - 실제 HTTPS/도메인/SMTP 검증
  - 모바일/실사용 흐름 검증
- 특징
  - 외부 접속 가능
  - 실제 메일 링크/세션/쿠키 검증 가능
  - 정식 공개 전 검증 환경

---

## 2) 운영 흐름 (반복 루프)

```text
맥미니에서 개발
 -> 기능 단위 묶음(테스트 가능한 덩어리)
 -> 28 서버 반영
 -> 외부 테스트
 -> 이슈 발견 시 맥미니에서 수정
 -> 28 서버 재반영
 -> 안정화
```

핵심 원칙:
- 기능 하나 바꿀 때마다 즉시 배포하지 않음
- "테스트 가능한 단위"로 묶였을 때만 28 반영

---

## 3) 28 반영 대상 단위 (권장)

아래 중 하나가 최소 1세트로 동작하면 반영 대상:

- 학생 등록 흐름
- 로그인/비밀번호 재설정 흐름
- 학생 예약 화면
- 관리자 예약 화면
- 보호자 화면
- 레슨노트 흐름

---

## 4) 반영 전 체크리스트 (맥미니)

- [ ] lint 통과
- [ ] build 통과
- [ ] 주요 페이지 진입 확인
- [ ] 일본어 문구 자연스러움 확인
- [ ] 권한(Role)별 접근 오류 없음
- [ ] 치명적 레이아웃 깨짐 없음
- [ ] 등록/로그인/세션 기본 동작 정상

실행 권장:
- `npm run lint`
- `npm run build`

---

## 5) 반영 후 체크리스트 (28 스테이징)

- [ ] 외부 접속 가능
- [ ] HTTPS 정상
- [ ] 로그인 가능
- [ ] 등록 메일 수신 가능
- [ ] 메일 링크 클릭 가능
- [ ] 학생/보호자/관리자 권한 정상
- [ ] 모바일 화면 확인
- [ ] 세션/쿠키 문제 없음

메일 관련 핵심 확인:
- `MAIL_SEND_MODE=smtp`
- 등록 API 응답에서 `mail.sent=true`

---

## 6) 브랜치/배포 흐름 제안

권장 구조:
- `main`: 안정 기준 버전
- `staging`(또는 `dev`): 28 반영 기준 버전

권장 프로세스:
1. 맥미니에서 기능 개발
2. 기능 단위 테스트 완료 후 `staging` 반영
3. 28 서버는 `staging` 기준 배포
4. 외부 테스트 안정화 후 `main` 반영

목표:
- 개발 중 코드와 외부 테스트 중 코드를 명확히 분리

---

## 7) 환경변수 운영 기준

## 맥미니 (개발)
- 로컬/개발 주소 기준
- 필요 시 `MAIL_SEND_MODE=log` 또는 테스트 SMTP

## 28 서버 (스테이징)
- 실외부 접속 기준 설정
- `APP_BASE_URL` = 실제 외부 접근 주소
- `MAIL_SEND_MODE=smtp`
- 실제 SMTP 발송값
- HTTPS 기준 쿠키/리다이렉트 검증

원칙:
- 같은 코드라도 환경변수는 분리 유지

---

## 8) 도메인 전략

최종 목표:
- `hanguru.school` -> 메인 사이트
- `portal.hanguru.school` -> MalMoi 포털
- `hanguru.blog` -> 블로그

현재 권장 순서:
1. 28 서버 임시 외부 주소로 스테이징 검증
2. 안정화 후 `portal.hanguru.school` 연결
3. 정식 공개 전 최종 점검

---

## 9) 지금 단계 우선순위

1. 로그인/등록/동의/개인정보 흐름 안정화
2. 실제 메일 발송 흐름 안정화
3. 학생/보호자/관리자 기본 동선 점검
4. 28 스테이징 반영 준비 및 외부 테스트 시작

---

## 10) 28 반영 시작 전 최소 조건 (Go 조건)

아래 조건을 모두 만족하면 28 반영 시작:

- [ ] 등록 시작 -> 메일 발송 -> 링크 클릭 -> 동의 -> 개인정보 입력 플로우 정상
- [ ] 로그인 -> 필수 비밀번호 변경 플로우 정상 (`mustChangePassword`)
- [ ] 학생/보호자/관리자 기본 접근 경로 정상
- [ ] lint/build 통과
- [ ] 치명 오류(화이트스크린/500/권한 누락) 없음

---

## 11) 운영 메모

- 정식 공개 전까지 학생 대상 공식 안내는 하지 않음
- 외부 테스트가 필요한 시점에만 28 반영
- 이슈 수정은 맥미니에서 우선 처리 후 스테이징 갱신
