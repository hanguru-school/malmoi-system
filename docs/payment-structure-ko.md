# 결제 구조 (외부 결제 미연동)

## 저장 위치

- 시스템 설정의 **`paymentMethodsPolicy`** 섹션 (`/admin/settings/payments-usage`).
- 실제 거래·포인트 데이터는 기존 **결제 관리** 화면/API 를 사용합니다.

## 결제 수단(마스터)

기본 4종:

1. **교실에서 결제** — 현장 수납 후 관리자가 이용 시간(포인트/분)과 연결하는 운영을 전제.
2. **Web 결제** — Square/Stripe **선택 UI만** 제공, 실제 API 연결은 하지 않음.
3. **은행 송금**
4. **기타**

각 항목: **사용 여부**, **학생 표시**, **관리자 확인 필요**, **설명 문구**. Web 은 추가로 **provider 선택(none/square/stripe)**.

## Web 프로바이더 “준비” 플래그

- `webProvidersPrepared.square` / `stripe` 는 운영 메모용 불리언일 뿐, 결제 게이트웨이와 통신하지 않습니다.

## 교실 결제 흐름

1. 현장에서 결제
2. 관리자가 시스템에 반영(이용 시간·포인트 등)
3. 예약/수업 단위와 연계 (세부는 결제 엔진·운영 규칙에 따름)
