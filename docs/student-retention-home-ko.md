# 학생 홈「次の一手」재방문 유도

## 목적

プッシュ通知を増やさず、**学生ホーム画面上**で「次に何をすべきか」が一目で分かるようにする。条件に応じてタイルの強調（`data-emphasis`）と短い説明文を切り替える。

## 우선 규칙（要約）

1. **未完了の宿題**がある → 宿題タイルを強調、ヒントで件数・行動を案内。
2. **予約日が今日または明日**（残り0〜1日）→ 予約タイルを強調、「本日／直前の確認」系の文言。
3. **3日以内の予約**（上記以外）→ 予約タイルを強調、「近日の予約を確認」。
4. **直近のレッスンノート**があり、上記に該当しない → ノートタイルを強調、「復習・ノート確認」。
5. **次の予約がない**、または **14日より先だけ** → 予約タイルで「予約する」等を強調。

## 주요 동선

- 学生がマイページ（ホーム）を開く → 「次の一手」見出しの下に **1行のヒント**（該当時）と3タイルが表示される。
- タップで 予約一覧／ノート一覧／宿題一覧へ遷移（既存ルートのまま）。

## 롤백

- UI文言・優先ロジックは `app/student/StudentDashboard.js` と `app/student/student-home.module.css` に集約。Git で当該コミット前に戻す。
- サーバー・セッション・API の変更は不要。

## 운영 주의점

- 画面文言は日本語のまま維持する（運用ドキュメントは韓国語可）。
- 「次の一手」はあくまでガイドであり、強制遷移はしない。
- `todayYmd` と予約日の比較はクライアント表示用データに依存するため、サーバー側の日付境界（タイムゾーン）と極端にずれないよう、既存のダッシュボードデータ供給を維持すること。
