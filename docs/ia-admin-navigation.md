# 管理者 IA（情報構造）

## 主要目標

- **運用の核**を上に: **学生管理 → 予約管理 → 登録状況 → お知らせ**（`AdminTopNav` 先頭付近）。  
- **決済**を独立グループに。  
- **監査ログ → 保存診断 → システム設定**（＋管理者設定）は下位グループで、誤操作しにくい位置にまとめる。  
- レッスンノート・宿題・メール・保護者・ダッシュボードは従来リンクを維持しつつ、上記の後に続ける。

## よくある行動

1. 学生・予約・登録・お知らせ  
2. ダッシュボードで当日 KPI  
3. レッスンノート・宿題  
4. 決済  
5. 不整合時のみ保存診断・監査
