# MalMoi — 접근 방식과 알림 (확정 정책)

본 제품은 **외부 메신저(LINE 등)와의 연동을 제공하지 않습니다.**

## 접근·인증

- **이메일** — 로그인, 링크 기반 절차(비밀번호 재설정 등)
- **전화번호** — 학생 프로필·초기 비밀번호 정책 등과 연계
- **학생번호** — 식별·지원 문의 시 참조
- **비밀번호** — 계정 보안

LINE 로그인, LINE 계정 연동, LINE 経由の予約・ノート・宿題導線、LINE マイページ、LINE 通知・リマインダは **対象外** です。

## 알림

- 기본 채널은 **SMTP 이메일** (관리자 설정·`MAIL_*` / `SMTP_*` 환경 변수와 연동).
- **포털 내** 공지(お知らせ), 예약·결제 이력, 레슨노트, 숙제 화면에서 상태를 확인하는 흐름을 전제로 합니다.

상세 구조는 `master-architecture.md`를 참고하세요.
