# 자동 체크·오늘 완료 표시·학생 리텐션·선생 개인화 (운영 문서, 한국어)

## 1. 목적

- **기능 확장**이 아니라 **클릭·판단 부담 감소**와 운영이 **자동에 가깝게** 느껴지도록 한다.
- 서버 JSON 스키마·`AUTH_STORE_PATH`·기존 REST 경로는 **변경하지 않는다**.
- 위험한 일괄 상태 변경(되돌리기 어려운 조작)은 **자동화하지 않는다**.

---

## 2. 자동 체크·기본값 정책

### 2.1 숙제 (先生/管理者)

- **提出済み → 確認済み**: 목록에서 **「確認済みにする」** 한 번으로 `PATCH` (기존 API). 상태 드롭다운을 열지 않아도 된다.
- **先生**이 목록이 **すべて提出済み**일 때: 체크박スを **自動で全選択**し、一括「確認済み」しやすくする（ユーザーは変更可能）。
- **新規宿題**: 公開は既定でオン、レッスン日・提出期限はノート連携時に sessionStorage から補完（既存 `quickHomework`）。
- **やらないこと**: 未確認の宿題を勝手に「完了」にする、削除の自動化、学生への通知ロジックの変更。

### 2.2 レッスンノート (先生)

- **タイトル未入力**: 保存時に **「レッスンノート」** を自動適用（空タイトルでの失敗を防ぐ）。
- **日付未入力**（先生クイックUI）: 保存時に **当日**を補完（`localTodayYmd`）。
- **公開**: 既定は学生向け共有オン（既存フォーム）。
- **やらないこと**: 既存ノートの一括上書き、非公開の自動切替。

### 2.3 主要動선

先生: 本日の未処理 → 宿題/ノートリンク → ワンタップ確認・保存 → 連続キューで次へ（別ドキュメント `ops-today-bulk-risks-ko.md` 参照）。

### 2.4 롤백

- 宿題: `AdminHomeworkPanel` のボタン・自動選択 `useEffect` を削除すればよい。
- ノート: `AdminLessonNotesPanel` の `safeTitle` / `safeDate` 補完を削除すればよい。

### 2.5 운영 주의

- 自動補完は **保存直前**のみ。画面上の未入力のまま意図を変えない。
- API エラー時は従来どおりメッセージ表示。

## 3. 오늘 완료 상태 표시 (`/teacher/ops-today`, `/admin/ops-today`)

### 3.1 표시内容

- **全体**: 当日セッションで観測した **最大残件数（ピーク）**。
- **完了**: `ピーク - 現在の残件`（サーバー再計算で残件が減った分）。
- **残り**: 現在のバックログ件数の合計。
- **完了率**: `完了 / 全体 × 100`（未処理ゼロかつピークゼロは「—」）。
- **本日完了**バッジ: 残り0かつピーク>0 のとき。

### 3.2 実装メモ

- クライアント `OpsTodayProgressHeader` が `remaining` を受け取り、`useEffect` で `peakRemaining = max(peak, remaining)`。
- ページを開いたタイミングでピークが更新されるため、**同日にタスクが増えた場合**もピークが伸びる。

### 3.3 롤백

- コンポーネントとページからの import を外す。

### 3.4 운영 주의

- 「全体」は **厳密な業務上の総タスク数**ではなく、**その日ブラウザで見た未処理のピーク**に近い。説明時は「目安」と伝えるとよい。

## 4. 학생 홈「次の一手」条件（リテンション）

### 4.1 優先順（1つのタイルだけ `data-emphasis="high"`）

1. **未完了の宿題がある** → **宿題**を強調。
2. **次の予約が3日以内**（当日含む） → **予約**を「次の予約を確認」で強調。
3. **最近のレッスンノートが1件以上**（ホームに渡す件数内） → **ノート**を「ノートを確認」で強調。
4. **予約がない**、または **次のレッスンが14日より後** → **予約**を「予約する」で強調。
5. それ以外 → すべて `low`。

### 4.2 やらないこと

- 追加のモーダルやプッシュ通知は増やさない。ホームの3タイルで完結。

### 4.3 롤백

- `StudentDashboard.js` の `retentionFocus` 計算とタイル文言を元に戻す。

### 4.4 운영 주의

- `recentLessonNotes` はサーバーで **先頭数件のみ**渡すため、「最近」の定義は **表示サンプル基準**である。

## 5. 先生個人化の準備（localStorage）

### 5.1 キー

- `malmoi:teacherUiUsage:v1`（スキーマ v2 を JSON 内 `v` で表現）。

### 5.2 収集項目

- **プリセット**: id ごとに `count`, `lastUsedAt`（ISO）、**最近使った順** `presetRecent[]`。
- **テンプレート**: 同様に `templates`, `templateRecent`。
- **直近の宿題再利用**: `recent.reuse` に count / lastUsedAt。

### 5.3 利用箇所（現状）

- クイック定型ボタンの **並び順**: `sortPresetIdsByUsage`（最終利用時刻 → 回数 → 最近順）。

### 5.4 롤백

- ブラウザの localStorage キー削除、または `teacherUiUsage.js` を旧版に戻す。

### 5.5 운영 주의

- **個人ブラウザのみ**。サーバーに送信しない。クリア手順はブラウザのサイトデータ削除。
