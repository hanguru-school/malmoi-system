# 선생님 UI 개인화 (빠른 입력 순서)

## 목적

브라우저 `localStorage`에만 저장되는 사용 이력(횟수·최종 사용 시각·최근 ID 순서)을 이용해, **자주 쓰는 항목이 위쪽에 오도록** 버튼·드롭다운 순서를 바꿉니다. 서버 JSON·REST API 스키마는 변경하지 않습니다.

## 적용 대상

| 영역 | 동작 |
|------|------|
| 레슨노트（先生クイック入力） | 定型テンプレート、学習ポイント（ワンタップ） |
| 宿題 | クイック定型ボタン、保存テンプレート（`<select>` の並び） |

## 주요 동선

1. 先生がテンプレ適用・ポイント挿入・宿題クイック定型／テンプレ適用を行うたびに `lib/teacher/teacherUiUsage.js` が記録する。
2. 次回以降、同じ画面を開くと **最終利用が新しい → 利用回数が多い → 既定の並び** の優先で並べ替えられる。
3. 複数端末・ブラウザ間では共有されない（ローカルのみ）。

## 롤백

- 並びを既定に戻したい場合: 브라우저 개발자 도구で `localStorage` 키 `malmoi:teacherUiUsage:v1` 을 삭제한다.
- コードロールバック: `teacherUiUsage` の SCHEMA 変更や各パネルの import を元に戻す（Git で戻す）。

## 운영 주의점

- プライベート端末以外では、共有PC利用時に並びが前ユーザーの履歴を反映しうる。
- ストレージ拒否・容量超過時は記録が無視され、既定順のまま表示される。
- 宿題の「保存テンプレ」は API の `id` 単位で集計する。テンプレ削除後も古い id が残る場合は手動でキー削除可。
