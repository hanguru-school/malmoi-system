## 共通の技術原則

- `AUTH_STORE_PATH`、セッション、メール verify、REST、JSON 保存形式は変更しない。  
- 予約・登録の V1/V2 は `?ui=v1` / `?ui=v2` と環境変数でロールバック可能（`docs/registration-v2-integration.md`）。

## 学生

| 項目 | 要約 |
|------|------|
| 主要目標 | 予約を最優先に見せる |
| よくする行動 | 予約 → ノート・宿題 → お知らせ → プロフィール |
| メニュー順 | ホーム → 予約 → ノート → 宿題 → お知らせ → プロフィール → 学習状況 |
| ホーム優先度 | 次の予約 → 利用状況 → 大きな「予約する」→ ショートカット 4 → 学習系 → お知らせ・プロフィール |
| モバイル | 上段に予約 CTA、タップしやすいグリッド |

## 管理者

| 項目 | 要約 |
|------|------|
| 主要目標 | 日次運用を上、システム・権限を下 |
| よくする行動 | ダッシュボード → 予約・学生 → 記録・お知らせ → 決済 |
| メニュー順 | グループ「日次運用」→「決済・連絡」→「システム・監査」 |
| ホーム優先度 | 承認待ち・本日・KPI・監査の直近 |
| モバイル | ドロワーをグループ見出し付きで表示 |

## 先生

| 項目 | 要約 |
|------|------|
| 主要目標 | 授業進行と記録中心（決済・全権編集は対象外） |
| よくする行動 | 当日レッスン → ノート → 宿題 → 生徒確認 |
| メニュー順 | ホーム → レッスン・予約 → ノート → 宿題 → 生徒 → お知らせ（案内）→ 進捗 |
| ホーム優先度 | 要対応 KPI → 各機能リンク → お知らせ運用 |
| モバイル | メニュー項目を絞り、縦リスト中心 |

## ロールバック（本 IA 更新）

- **UI のみ**: 上記「変更ファイル」表にあるコンポーネントを Git で元に戻す。  
- **データ・API**: 触っていないため不要。  
- **詳細手順**: `docs/operations-v2-verification-checklist.md` のロールバック節。
