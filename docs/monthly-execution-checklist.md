- 인증·알림: 이메일·전화·학생번호·비밀번호 기반. 외부 메신저(LINE 등) 연동 없음. 알림은 메일 + 포털 공지·이력 중심

- 상세 설계 기준은 `docs/master-architecture.md`를 단일 기준으로 사용
