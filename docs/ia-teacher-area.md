# 先生（教師）エリア IA（情報構造）— 初期案

## 主要目標

- **授業の進行**と**記録**（レッスンノート・宿題）を中心にし、決済・システム設定・全学生の一括編集はスコープ外。  
- **今日のレッスン**（`/teacher/today`）と**予約一覧**（`/teacher/schedule`）は同じリスト UI。旧 `/teacher/lessons` は `/teacher/today` にリダイレクト。

## よくある行動

1. 当日の担当レッスンの確認・進行  
2. レッスンノートの作成・確認  
3. 宿題の確認・フィードバック  
4. 生徒の検索・メモ・学習状況の参照  
5. 教室からの連絡事項の把握（運用は管理者経由も可）  

## 推奨メニュー順（`TeacherTopNav`）

| 順 | ラベル | パス | 備考 |
|----|--------|------|------|
| 1 | ホーム | `/teacher` | KPI・お知らせ案内 |
| 2 | 本日のレッスン・予約 | `/teacher/today` / `/teacher/schedule` | 日付変更は予約一覧側 |
| 3 | レッスンノート | `/teacher/lesson-notes` | |
| 4 | 宿題 | `/teacher/homework` | |
| 5 | 生徒メモ・検索 | `/teacher/students` | |
| 6 | お知らせ | `/teacher#teacher-notices-area` | ホーム内アンカー（運用説明） |
| 7 | 学習進捗 | `/teacher/progress` | 補助 |

## 「今日のレッスン」と「予約一覧」

- 実装は **`TeacherDayView`**（`/teacher/today`・`/teacher/schedule`）。日付フィールドで任意の日を選ぶと、その日の担当予約が一覧になる。  
- メニュー表記は **「本日のレッスン・予約」** に統一し、IA 文書で二重表記を避ける。

## お知らせ

- 専用の教師向けお知らせ一覧 API は未整備の場合がある。  
- ホームに **`#teacher-notices-area`** で運用ガイドを表示。将来的に読み取り専用一覧を足す場合は本セクションを置き換え可能。

## ホーム / ダッシュボードの優先順位

1. 今日の担当件数・未作成ノート・提出済み宿題などの **要対応**  
2. 各機能への **短いリンク**（レッスン・ノート・宿題・生徒）  
3. **お知らせ**（運用テキスト）  

## モバイルの考慮

- 教師もスマホ利用を想定し、メニューはドロワーで **7 項目程度** に抑える。  
- レッスン一覧は日付＋リストで縦スクロールしやすくする（既存ページに準拠）。
