# 강사·보호자 등록 (초대 기반)

## 원칙

- **자유 가입은 금지**하고, **관리자 초대 링크**를 통한 등록을 전제로 합니다.
- 역할(강사/보호자 등)은 초대 시점에 고정됩니다.
- 초대 발급·가입 완료·관리자 프로필 변경 등 민감 동작은 **감사 로그**에 남깁니다.

## 강사

1. 관리자가 초대 생성 → 메일/링크 전달  
2. 수신자가 링크로 접속 → 비밀번호 설정  
3. 프로필 입력 → 완료  

관련 API·화면: `/admin/settings/accounts`, `role-invitations`, `/register/invite` 등.

## 보호자

1. 관리자가 학생과의 연결을 전제로 초대  
2. 가입 후 학생과 계정 연결  

## 관리자 계정 확장

- 표시명·이메일(SUPER만)·전화·프로필 이미지(data URL)·직책·서명 메모 등은 `PATCH /api/admin/admin-users/[id]` 및 저장소 `updateAdminUserProfileByAdmin` 로 반영됩니다.
- 알림·메시지 UI에서 관리자 이미지를 쓰려면 해당 필드를 표시 컴포넌트에서 읽으면 됩니다.
