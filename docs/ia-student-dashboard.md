# 学生エリア IA（情報構造）

## 主要目標

- **予約**を最優先。上段は **次の予約 → 利用状況 → 大きな「予約する」**。  
- **中段**は **予約一覧・レッスンノート・宿題** の 3 タイルのみ。  
- **下段**は **お知らせ** と **プロフィール**。  
- それ以外（今日の学習・ノート/宿題の抜粋・カレンダー・記録）は **「詳細・記録」** ブロックにまとめ、下段の下に配置。

## よくある行動

1. 予約の新規・一覧・変更・キャンセル  
2. レッスンノート・宿題  
3. お知らせ・プロフィール  

## 推奨メニュー順（`StudentAreaLayout`）

| 順 | ラベル | パス |
|----|--------|------|
| 1 | ホーム | `/student` |
| 2 | 予約（予約する・一覧） | `studentReservationsPathFromBrowserPreference()` |
| 3 | レッスンノート | `/student/lesson-notes` |
| 4 | 宿題 | `/student/homework` |
| 5 | お知らせ | `/student/notices` |
| 6 | プロフィール | `/student/profile` |
| 7 | 学習状況 | `/student/progress` |

## ホーム / ダッシュボードの優先順位（実装）

1. ヒーロー  
2. **次の予約**  
3. **利用状況**  
4. **大きな CTA「予約する」**  
5. **メイン** — 予約一覧 / レッスンノート / 宿題（3 タイル）  
6. **お知らせ**  
7. **プロフィール**（ストリップ）  
8. **詳細・記録** — 今日の学習、最新ノート、宿題抜粋、ミニカレンダー、最近の記録  
9. **その他** — 決済履歴・学習状況  

## モバイル

- 上段に予約 CTA、中段は 2 列（狭い画面）〜 3 列（広い画面）。
